# SOUL RUSH CLASSIC 0.2.2

原作 Rune Rider (111%, 2017) を参考にした非公式の独立再構築版。既存のSOUL RUSH v0.18は変更しない。通常24秒、特殊6秒、武器7種、ルーン33種、5ビルド、同種素材+ゴールドによる育成。ホーム/装備/戦闘/報酬画面を参考画面の構造に寄せ、自作SVGで武器・キャラ・敵・ルーンを描画。元のロゴ、画像、コード、音楽は使用していない。

- セーブ: soul_rush_classic_v9。旧SOUL RUSHのセーブ/復元とは分離。バックアップにはedition識別子が必要。
- 原作未確認の数値: 初期敵HP29（24秒版の遊び始めを調整）、武器性能、ルーン倍率、配置、報酬、ドロップ、ヘルメット解放、等は仮仕様。原作の素材そのものや完全なピクセル一致は再現していない。
- 追加した独自の魂工房・自動編成は再現版では無効。攻撃範囲の表示と詳細分析は検証用途として残す。アリーナは従来NPC対戦。
- 参考: https://appget.com/appli/view/70954/ / https://www.behance.net/gallery/66921429/Rune-Rider-UI-Weapons-Helmets-and- / https://forum.gamer.com.tw/B.php?bsn=33387
- 起動: リポジトリルートで python -m http.server 8000 を実行し http://localhost:8000/classic/ を開く。
- reference.json は既存ベースの変更点を管理する。独立HTML内マスターは現時点で手動同期。
- テスト: node --test tests/classic.test.cjs ; node tests/classic-browser-smoke.cjs

## 0.1.2 UI調整
- 装備画面は一覧中心。武器7種の2列タイルとルーン33種の4列タイル、LEVEL/LOCK・素材バー・装着チェック。詳細は選択時のみ開く。ソート・絞り込みと強化は引き続き利用可能。
- 画面端まで使う装備/戦闘レイアウト。戦闘中の独自の範囲投影・移動距離・ゴールゲージ等を非表示とし、ATK/SPDアイコン・数値・発動カウントを優先。既定44:56の上下分割を維持。射程プレビューはルーン詳細から参照可能。
- 武器獲得時に武器SVGを表示。24秒/6秒・既存の戦闘・強化・保存キーは変更なし。戦闘エンジンのscript内容は0.1.1と同一。
- 公開画像を参考にした近似再構築。原作の完全な画像一致やソースコードの複製、実機での照合は行っていない。

## 0.1.3 戦闘演出と実演モード

## 0.1.6 装備表示と報酬操作

## 0.1.8 ルーン発動・装備比較
- 33ルーンの詳細から「発動・性能試算」。未所持Lv1・既存装備・次Lvを現在AREAで同一seed/ボス種により比較。仮装着する場合は交換対象を明示し、所持Lvとセーブを変更しない。
- 時間型の実効周期、小型化や黄金の剣等の補助効果を含む実戦試算、発動/命中/実DMG/無効/空振り、最大ATK/SPD、1秒刻みの成長、撃破数とゴールドを表示。補助効果は直接DMGではなく総合結果で確認する。
- 戦闘ゲージは時間型の残り秒を表示し、戦闘終了後の発動点灯を消す。多段着弾では発動回数を加算しない。表示変更であり、エンジン・マスター・セーブキー・通常版は未変更。
- 資料: https://appget.com/appli/view/70954/ — パッシブ/攻撃回数/時間型、固定値と武器依存、攻撃範囲、速度30%と10回攻撃ごとの0.12上昇の記述。現行Lv1のhaste/tempoと一致。その他の正確な値は未確認。試算画面自体は原作に存在したことを確認した機能ではなく、再現検証の補助。
