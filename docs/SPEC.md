味方HP・防御・MP・手動スキル・属性相性・個体のランダム能力差は採用しない。課金・広告は当面対象外。
旧Rev.3の単一通貨、重複所持禁止、進化保留、一本道のみという将来方針を本改訂で置き換える。旧機能は段階移行する。

## 2. コア戦闘（B01〜B08）

- B01: 出撃1体、最大30秒の完全オート。準備・演出時間を除外。
- B02: 出撃時にモンスター・能力・魂構成を固定。戦闘中の変更禁止。
- B03: 味方左、敵右。先頭の生存敵を通常攻撃。撃破直後に次の敵を対象とする。攻撃間隔1/SPD秒、初回は1間隔後。
- B04: 有限敵の全敵討伐は全撃破で即終了。30秒ちょうどの攻撃も有効。無限討伐は30秒で終了予定。
- B05: 再挑戦は戦闘内状態を初期化。恒久育成を保持。
- B06: 解放済み地域・ステージ・ミッションは再挑戦可。解放後退なし。
- B07: 余剰通常ダメージは原則消失。貫通等の固有効果のみ後続へ伝播。
- B08: 敵数・HP・防御や特殊能力で差別化予定。現段階は敵数・HPのみ。

現行処理順: 通常攻撃→攻撃回数型追加攻撃→爆炎→月蝕。同時刻と30秒境界を維持。
報酬・XP・ドロップ・記録は終了時一度だけ確定。中断・未終了で付与なし。

## 3. ワールド・ミッション（13〜16）

8地域を基本とする。名称・範囲は暫定。旧100ステージを安定IDのまま配置する。

| 地域ID | 仮名称 | ステージ |
|---|---|---|
| forest | 始まりの森林 | 1–10 |
| ruins | 忘却の遺跡 | 11–20 |
| desert | 灼熱の砂漠 | 21–30 |
| frost | 凍結の大地 | 31–40 |
| demon | 魔界 | 41–50 |
| sky | 天空領域 | 51–60 |
| abyss | 魂の深淵 | 61–80 |
| other | 異次元領域 | 81–100 |

将来: 地域固有の敵・魂・素材・モンスター、ランク・アイテム条件による解放。
v0.4.0は旧進捗を尊重し、地域の最初のステージが解放されたら地域選択可。既存解放済みステージを再ロックしない。ランク・鍵条件は未実装。

4ミッションの試験仕様（v0.4.0、NORMAL、同じ有限敵戦闘を再利用）:
| ID | 目標 | 報酬 |
|---|---|---|
| main | 全敵撃破 | 既存の割合＋クリア報酬。次ステージ解放 |
| hunt | ceil(敵数/2)体以上撃破 | 割合＋達成報酬 |
| collect | ceil(敵数/6)個の魂の欠片 | 撃破3体ごとに欠片1個。割合＋達成報酬 |
| challenge | 25秒以内に全敵撃破 | 割合＋達成報酬 |

サブ3種は最初のメインクリアで解放。達成後も全敵撃破または30秒で終了。サブ達成報酬=floor(基準報酬×20%)（最低1）、メインボーナスとは併用しない。欠片は収集戦のみで獲得、未達成でも獲得分を保持。用途は後続実装。サブはメイン記録・解放進捗を変更せず、別の挑戦回数・成功回数・最高評価・前回記録を保存。通常XPと累計撃破報酬は共通。

評価: S=特別条件（メイン/チャレンジは20秒以内全撃破、討伐/収集は全撃破）、A=目標達成、B=目標75%以上、C=50%以上、D=50%未満。時間制約未達の全撃破はB。数値は試験用。
将来: NORMAL/HARD/EXPERT/MASTER/ABYSSの5難易度、初回報酬、通常周回、ランダムドロップ、特別条件報酬。v0.4.0はNORMALのみ、初回・ランダム報酬は未実装。無限討伐・専用ボス・レア戦等の独立ルールは次工程。

## 4. モンスター（17〜21）

- 種族（スライム・獣・竜・精霊・魔族・機械等）、N/R/SR/SSR/UR。高レアだけが常に最強にならない。
- ATK、SPD、CRIT、CRIT DMG、PEN、LUCK、SOUL SLOT。全種に固有能力。
- 召喚、捕獲、ミッション、進化、融合で入手。同種複数所持可、原則無制限、重複は育成に利用。個体差なし。
- 所持個体IDと種族IDを分離予定。現行4種モス、ヴォルフ、グラント、イグニスは種族単位で1体のみ。ATK/SPD/枠/魂適性・購入規則を維持。新所持モデルは後続。

## 5. 魂（22〜24）

- G08の5分類。ドロップ・購入・ミッション・合成・進化で入手。
- N/R/SR/SSR/UR、レベル強化、重複所持、無料着脱。1体に同名魂1個まで。枠はモンスター固有。
- 強化資源はエーテル・重複魂・素材。特定組み合わせのシナジー。増幅上限は後で設定。
- 現行7魂（力、疾風、雷鳴、爆炎、捕食、貫通、月蝕）と既存Lv・適性・累計撃破ドロップ・購入を保持。魂の複数所持、シナジー等は未実装。装着競合と個体データ移行を後続設計。

## 6. 育成・進化（25〜27）

| 機能 | 条件・効果 |

| 覚醒 | 同種個体・専用素材で固有能力強化 |

## 7. プレイヤー・ギルド・拠点（28〜31）

採用する詳細方針: 冒険者ランクはミッション達成で上昇し、地域・機能解放。スキルツリーは戦闘・育成・収集・経済。実績・称号は条件付き報酬。拠点は召喚所・魂研究所・育成所・融合所・交換所を基本案とする。全モンスターに共通成長を適用。ランク必要XP、ポイント入手量、効果上限、施設コストは未決定。未実装。

## 8. 経済

エーテル（通常強化）、魂結晶（希少交換）、地域素材（進化等）、ギルドポイント（限定交換）。売却・分解・交換。原則所持上限なし（安全上限あり）。
現行メイン割合報酬=floor(基準報酬×撃破数/敵数)、クリア時に既存ボーナス追加。XP=撃破数、0体なら0。再クリアもボーナス。周回効率・インフレは後続シミュレーション。v0.4.0はエーテルと魂の欠片のみ。欠片の消費先・希少通貨・交換・オフライン報酬は未実装。

## 9. UI（UI-001 / Rev.3）

固定ビューポート、1主シーンのみ、iPhone縦画面優先、安全領域対応、長い一覧のみ内部スクロール。常時タブバーなし。
メインターミナルを入口とし、ワールド・モンスター・魂・ギルド・拠点・ショップ・図鑑・設定へ。現行ビルドはモンスターと魂を統合、ギルド/拠点は後続。
起動→タイトル→ターミナル→ワールド（地域→ステージ→ミッション→出撃）→戦闘→リザルト→再挑戦・メイン次ステージ・ターミナル・ビルド・ショップ。
v0.3.1のタイトル往復/出撃/再挑戦/次ステージは青緑白1秒、メニュー暗転0.3秒、リザルト0.5秒を維持。動きを減らす設定では即時。戦闘時間に含めない。戦闘中/演出中の重複入力禁止。結果確定・保存は一度だけ。サブのリザルトはメイン次ステージボタンを出さない。

## 10. データと保存（SAVE-002）

- v1の保存キー soul_rush_prototype_v1 を読み取り専用の旧データとして保持。v2保存キー soul_rush_prototype_v2。
- v2が存在すればv2だけを読む。存在しない場合だけ旧v1を移行し、次回保存からv2に書く。旧キーは削除・更新しない。旧キャッシュ版と新版の進捗は同期しない。
- v1/v2 JSON復元。不明バージョン・読込失敗時は元データ保護、旧データへの無断フォールバック禁止。保護中のバックアップは読めた原文を出力。復元/初期化は保存成功後に状態を切替。
- 通貨、Lv、XP、魂、装着、解放、累計撃破、メイン記録と履歴の意味を保持。既存バリデーションを維持。
- v2追加: selectedMission、missionRecords（stage:typeキー）、materials.soulFragment。戦闘途中の再開は非対応。
- PWAキャッシュ識別子0.4.2、URL維持。実機で旧版を閉じてから更新。ブラウザデータ削除不要。
