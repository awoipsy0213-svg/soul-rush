## 1. 採用方針
- Rune Rider（2017年、111%）の戦闘・ビルド・経済・ステージ構造を再現してから独自要素を検討する。
- 原作確認済み、個人報告、未確認の実装仮値を区別する。元の絵・音源・コードは流用しない。
- 既存公開版のキャラID、魂ID、5ビルド、旧100ステージの進行・資産を保持し、長期AREAを追加する。
- 旧独自機能（ギルド、依頼、進化等）は追加しない。武器→モンスター、ルーン→魂というユーザー確定方針を維持。既存XP・凸の値と補正は移行で保護するが、新規のXP育成・凸強化・直接解放・25ジェム召喚は通常UIから廃止する。

## 3. 戦闘（BATTLE-015）
- 原作24秒に対し、ユーザー確定仕様の通常30秒を採用。末尾80型6秒。独立したアリーナ・Gift Runは従来の24秒。戦闘時間を超える攻撃は禁止。全敵撃破だけでなく、制限内のゴール到達で通常クリア。
- プレイヤーは一次元の世界座標を移動（暫定720論理px/秒）。敵の左端と幅・間隔を保持し、最前敵から接敵射程の位置で停止。移動と攻撃準備は同時に進行。全敵撃破後は最終敵右端+12へ移動する。敵自体は固定。開始位置0、先頭敵位置0。いずれも原作の正確な値ではない。
- 通常攻撃の前方区間と敵区間の重なりを検出し、最大命中数で打ち切る。魂の単体検索、前方範囲、対象中心の爆発半径は独立。爆発は前方の敵を検索して着弾中心から判定し、プレイヤー後方は除く。敵矩形のY座標・高さ、直線/扇形（前方三角形）/円形、連鎖・定位置持続・対象優先・確率の設定基盤を追加。既定の敵Y=0・既存形状は保ち、未確認の候補は試験用設定に留める。敵小型化で幅と間隔を同倍率縮小。多段は初回対象IDを保存し、生存者に追撃。
- 同時イベント順序：ゴール到達→通常攻撃→攻撃回数発動→時間発動→予約追撃→移動目標更新。通常攻撃のみ回数を加算。時間発動で範囲外の場合もクールタイムは消費。全滅/中止/時間切れで予約攻撃停止。通常戦闘はゴールへ、アリーナ/Gift Runは全滅で終了。
- 速度は秒間攻撃回数。開幕3秒の境界を積分し、途中の速度変化でも残り攻撃作業量を維持。ATK/SPDは固定値・基礎割合・現在値乗算を設定可能（既存バフは加算設定）。バフ上限、速度40/秒、周期下限0.2秒、イベント予算12000、乗算上限1e9。戦闘ごとに一時バフリセット。
- ポーズ、非表示時停止、撃破途中の報酬を維持。計算と描画は独立し、シードは保存記録へ追加。通常報酬は状態コピーを保存してから確定。失敗時は未保存画面で再試行/明示破棄。ページ離脱時の未保存報酬保持は保証しない。

### 戦闘演出・分析（FX-016）
- 通常攻撃、斬撃、雷、炎、氷、飛翔、隕石、波動、強化を自作SVGで視覚化（斬撃は通常攻撃と共通、計8系統）。発動した魂名を表示する。原作素材やコードは不使用。
- 戦闘エンジンが発動ごとの連番、時刻、魂ID、対象、基礎攻撃値を記録。演出用履歴は直近24イベントまで。画面1更新につき最大4演出を生成し、混雑時は省略。低モーション設定とゲーム内軽量演出設定では演出を省略。画面外の敵表示を省略、演出ノード上限36、描画1更新最大4。演出省略は命中・報酬に影響しない。v0.16では最大36のDOM演出ノードを再利用し、同一更新内の実ダメージを集約。敵の区間二分探索と可視敵のみDOM更新。影刃・飛翔・竜撃・星船・狙撃・会心等に専用SVG、撃破粒子、短い背景振動、ボス専用表示を追加。時間や攻撃判定を止める本物のヒットストップは未採用。
- 通常攻撃および魂別の発動数、攻撃が生存敵に到達した回数、実HP減少量、障壁/一撃条件の無効回数を集計。多段攻撃は初回のみ発動数を加算、実際の追撃を命中/ダメージとして計上。固定値バフ等は発動数のみ計上する。浮遊ダメージ数字は直近イベントの実HP減少量を対象単位で集約し、無効時はBLOCK。多数のイベントは描画を間引くので全イベントの画面上表示を保証しない。
- リザルトの「戦闘詳細」で各攻撃の実ダメージ内訳・回数を表示する。実ダメージは対象HPを超えない。間接的な強化によるダメージ増加は、実際に命中した攻撃源の側へ計上する。実ダメージ、DPS、最大ATK/SPD、最大命中数、魂別平均命中数、3秒/6秒/後半ダメージ、余剰ダメージ、残HP、移動距離/時間、前回同ルール比較を追加。

### 長期AREA（AREA-012）
- 解放上限100→10000。原作の真の上限ではなく、実装上の安全上限。1〜20面の敵HP・通常報酬は旧値を維持。100ごとに特殊ボス周期と背景8種を再使用。
- AREA40/140等の一撃必要値は round(500+2000×max(0,AREA-40)/3000)。AREA3040が2500になるように個人報告に合わせた仮式。500の開始値やその他の面の数値は未確認。
- 通常敵HPは20面まで旧曲線、20面以降は HP基準20×(1+(AREA-20)/60)^0.65。後半の数値は実装仮値。通常敵数の追加分は80体を上限とし、特殊大群310体は固定。ゴールド・ボーナスは30面まで旧指数曲線、以降は30面値×(1+(AREA-30)/40)^0.85。通常敵HPと通貨成長を別管理する。
- 戦闘時の最大一撃・実際に通った最大ダメージ・総実ダメージ・無効化回数を内部記録する。一撃ボスは必要値と最大一撃を戦闘中/結果に表示。障壁の無効回数も結果に表示。
- ステージ選択のリストは100面単位で分割し、解放済みの任意番号に移動するダイアログを追加。未解放、非整数、上限超過は拒否。

### アリーナ（ARENA-012）
- 20ジェムで入場、NPCを自動生成して対戦、勝利で連勝数増加。10勝ごとモンスター1体分を未受取報酬に加算。撤退でまとめて受取、1敗で未受取分を失う。ここまでのルールは原作の個人攻略報告を根拠とする。
- 次の相手・魂・Lv、現在ビルド、連勝と最高連勝、未受取報酬を表示。編成に戻っても連勝を保持。入場時に最高魂Lvとシードを固定、連勝数で次相手を決定し、再読込で相手を引き直せない。
- 原作の正確な対戦HP、判定時間、AI難易度式、ルーンの対戦専用効果は不明。現実装は24秒、600基準HPをLv・旧凸で補正、通常戦闘エンジンで双方の攻撃を同時時系列計算。同時撃破・同率タイムアップは敗北。単独撃破またはタイムアップ時残HP率が相手より高ければ勝利。強敵混入8%、最高1000連勝は実装仮値・安全上限。原作のネット対戦とは主張しない。
- 報酬: 勝数×60エーテル、勝数×7魂、10勝ごと1モンスター。2017-11-28個人実測に基づき1→7魂へ修正。入場時の最高魂Lv+4程度を相手ルーンLv上限の目安とするが、敵の生成式は暫定。通常ステージの撃破報酬はアリーナに入らない。
- 入場/対戦結果/撤退/購入をコピー上で処理し、保存成功後に状態更新。対戦結果を確定してからHP演出するためリロードで敗北回避や二重受取を防ぐ。保存失敗時は通貨・報酬を変更しない。

### ギフト（GIFT-013）
原作の2018年配信説明でデイリーギフトとGift Runの存在を確認。以下の数値・ルールは全て暫定で、原作の正確な値ではない。
- デイリーギフト：日本時間0時切替、無料で1日1回、4ジェム、魂3個、最高解放AREA×20エーテル。
- Gift Run：無料で1日1回、通常の装備と戦闘エンジンを使用し24秒以内に24体を撃破。敵HPは最高解放AREA基準の42/47/52/57%を反復。敵幅24（小型化反映）。通常戦闘/アリーナと精算を分離し、通常面解放、初クリア、撃破累計、通常ドロップには影響しない。
- 報酬は撃破数×最高解放AREAエーテル、6体につき1ジェム、3体につき魂1個。抽選は均等の仮設定。結果は挑戦開始時に確定して保存し、HPと撃破数のタイムラインを再生。未受取は次回起動でも保持し、受取成功時にのみ付与。前日分が未受取の間は新規挑戦不可。
