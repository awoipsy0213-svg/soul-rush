## 3. 戦闘（BATTLE-010）
通常24秒、末尾80型は6秒。全敵撃破で終了、制限時間ちょうどの攻撃は有効、時間後の攻撃は禁止。自動戦闘で一列の敵が並び、先頭の敵を攻撃起点とする。
敵幅と間隔から累積座標を算出。範囲は先頭の生存敵の左端から後方へ届く距離（論理ピクセル）。範囲内の生存敵すべてへ通常攻撃。単体魂は先頭1体、範囲魂は固有距離。小型化は敵幅と間隔を同じ倍率で縮小。正確な原作の範囲・命中方式は不明のため近似。
通常攻撃→回数発動→時間発動→予約された追撃の順。攻撃回数は通常攻撃のみ増加。速度は毎秒攻撃回数で扱い、開幕3秒の速度変化を攻撃進捗に反映。40回/秒の安全上限、時間型0.2秒の下限、イベント予算12000。戦闘終了・中止で予約攻撃を破棄。
ATK累積バフは基礎補正に加算、SPD累積バフは絶対値で加算。戦闘開始ごとにリセット。ポーズ・バックグラウンド停止、中止時の獲得済み報酬、二重精算禁止を維持。
接敵の移動時間・敵の物理的な移動は未再現。原作の移動挙動は映像検証が必要。

- 覚醒 opening: 開始3秒間SPD2倍（3秒は個人報告、倍率仮）
- 時律 timewarp: 時間発動間隔20%短縮、最大75%（効果の存在は個人報告、値は仮）
- 虚縮 shrink: 敵幅・間隔45%縮小、最大75%（効果の存在は個人報告、値は仮）
