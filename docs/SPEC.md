# SOUL RUSH ― 魂の系譜 基本仕様書
管理ID: SPEC-001 / Rev.9
更新: 2026-11-28
開発基準: v0.9.0
状態: 基本ループ簡素化。ユーザー指定の機能を実装。詳細の経済値・見た目は検証用の暫定値。

## 1. 採用方針

- 既存の公開URL・キャラクター・魂・育成データを維持する。新規ゲームを別途作らない。
- Rune Riderの24秒オートバトル、連続敵、装備5プリセット、3系統の発動、10ステージごとのボスを参考にする。名称・絵・コードは独自。
- 通常ステージだけを公開する。旧ギルド依頼、討伐・収集・チャレンジ、世界地図、商店・図鑑の独立画面は一旦休止。既存記録は保存。
- コア: ビルド→出撃→最大24秒戦闘→報酬→編成・重複強化→再挑戦または次ステージ。

## 2. 戦闘

- 味方1体、ATK・SPDのみ。先頭の敵に完全自動攻撃、全撃破で即終了、24秒時点の攻撃は有効。
- 全敵を出撃時に一列のDOMとして描画する。画面外も列は続く。表示範囲に合わせて敵を5体だけ生成する旧方式を廃止。撃破済み敵は非表示、列を移動する。
- ステージID 1〜100を維持。10・20・30…100をBOSSにする。暫定で10・30…は大型単体、20・40…は小型の大群。
- 通常攻撃→攻撃回数系→時間系の順。魂の発動・ダメージ・撃破エフェクト。
- HUDは残り時間・撃破進捗・ポーズ・下段の装着魂・獲得中報酬のみ。戦闘中のステージ番号・ログ・AUTO BATTLEラベルは非表示。
- 時間系は周期ゲージ、攻撃回数系はカウントゲージと発動表示、その他はアイコンのみ。
- ポーズ中は戦闘時間とBGMを停止。再開・設定・中止を選べる。中止はその時点までの撃破数・経験値・エーテル・魂を一回のみ確定しリザルトへ。初クリアやクリアボーナスは付与しない。バックグラウンドに移った場合もポーズ。
- 敵撃破時にエーテル額・ドロップした魂を浮遊表示。

## 3. 経済とドロップ

| 項目 | ルール |
|---|---|
| エーテル | 通常戦闘報酬。撃破割合分＋全撃破時のボーナス |
| ジェム（課金側通貨・仮称） | 通常初クリア5個。BOSS初クリアは合計20個。再クリア・中止は0 |
| BOSS初クリア宝箱 | キャラ1体＋魂5個をランダムで付与（内訳は暫定） |
| 魂ドロップ | 敵撃破ごと42%の抽選、既存累計撃破の確定枠、BOSS最後の敵の確定枠 |
| 魂強化 | 同一魂1個（被り）＋エーテル。初入手Lv.1、重複は素材。エーテルのみの習得や強化は廃止 |
| キャラ解放 | ジェムで直接解放、またはジェム召喚 |
| キャラ召喚 | 25ジェム、ヴォルフ・グラント・イグニス各1/3（仮設定） |
| キャラ凸 | 同キャラ1体（被り）＋エーテル。通常のエーテルのみ強化はなし |

暫定価格: 直接解放35/60/90ジェム。魂強化=基準価格×現在Lv、キャラ凸=150+100×現在凸。
実際の決済、課金購入、広告は実装しない。ジェムはゲーム内報酬のみ。ユーザー指定のない価格・確率・宝箱個数はバランス調整対象。

## 4. 育成とビルド

- キャラは既存4種、魂は既存13種。キャラ経験値は出撃中の撃破数に応じて取得。Lv上昇でATK・SPDが上がる。
- キャラ凸によるATK・SPD補正は1凸ごとに基礎倍率+15%/+5%（仮）。キャラLv・凸・魂Lvにゲーム設計上の上限なし。実装上はJavaScriptの安全な数値範囲内。
- ビルド5個。各ビルドにキャラIDと装着魂IDを保存し、変更時に自動保存する。魂・キャラのLvと素材は共通。
- ビルド画面は選択中キャラと現在装備のみ。キャラを押すと横スワイプのキャラ選択画面。魂枠を押すと縦スクロールのグリッド一覧。詳細で着脱・強化できる。
- 既存の魂枠数・適性・同一魂重複装着禁止を維持。

## 5. UI

- モバイル縦画面の固定ビューポート。タイトル・ビルド・戦闘・リザルトは画面全体のスクロールなしを目標。キャラ選択は横スクロール、魂一覧は縦スクロール。
- 全体をアイボリー・ラベンダー・ミントの明るいUIに統一。リザルトの暗色文字と暗背景の重なりをなくす。
- リザルトにエーテル・ジェム・経験値を表示。魂は中央からランダム位置へ一気に広がり、数が多いと重なる。領域内に収め、内訳ボタンで個数と新規取得を確認できる。BOSS初クリアの宝箱・キャラを別表示。
- BGM/効果音設定とJSONバックアップ・復元を維持。

## 6. セーブと移行

- v3の新しいlocalStorageキーを使用。v2/v1の旧キー・原文は変更しない。優先順位v3→v2→v1。
- 旧進行、所持エーテル、キャラLv/XP、装着魂、魂Lv/被り、旧ステージ・依頼記録を保持。停止中の旧依頼は通常ステージへ切り替える。
- 旧クリア済みステージには初クリアジェムを一度だけ遡及付与。旧BOSS該当面（10の倍数）も宝箱を補填する。v3再読込で二重付与しない。
- 旧装備を基に初期5プリセットを作成する。旧記録の30秒タイムと敵数を保持する。
- 未知バージョン/破損の最新キーを保護。無断上書きしない。実機のストレージは未確認。
