# UI-002 ギルド掲示板型 デザイン仕様書 Rev.1

対象: SOUL RUSH v0.4.1
状態: デザイン方向性確定／初回のテーマ実装
採用: ユーザーが比較画像C「ギルド掲示板型」を選択。

## 共通デザイン
- 中世ファンタジーの冒険者ギルド。木・羊皮紙・真鍮・革・封蝋、魂は紫の光。深紅の出撃ボタン。
- 背景: ギルドホール、梁、アーチ窓、紋章旗、ランタン。共通木目・羊皮紙・地図・紋章は独自SVGのデータURI。外部配信やフォント依存なし。
- パレット: 木 #372015、真鍮 #bf9252、紙 #dec18e、深紅 #67261d、魂 #d8b1ff。本文は視認性優先、見出しは明朝/Georgia系。
- 既存機能と入力導線、固定ビューポート、セーブv2、30秒・演出タイミングを維持。未実装のランク・施設・通貨の仮表示はしない。
- 既存のモンスター4体・魂7種のSVGは今回維持。高精細な独立立ち絵/魂アイコン、地域固有戦闘背景、施設別イラスト、サウンドは後続。比較画像は完成イメージでありそのままのUI画像は貼らない。

## 受入条件
- 既存38件のテストを維持。掲示板の動的情報、依頼の選択と直接出撃、保存互換を追加検証。
- 主要画面の外側にページスクロールを発生させない。短い画面ではターミナル内スクロールを許可し全ボタンへ到達可能にする。画面幅320pxを含むスマホ縦画面とデスクトップを確認。
- 戦闘エンジンと保存処理の内容はv0.4.0と同一。新規SVG/CSSはすべて自作コード。
- PWAキャッシュを0.4.1へ更新。iPhone実機・PWAオフラインは別検証。
