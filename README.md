## 遊び方

タイトル→ビルド→24秒戦闘→報酬→編成・重複強化→次のステージ。
ビルドのキャラを押すと横スクロールのキャラ選択、魂を押すとグリッド一覧。5つの装備構成を保存可能。
全ステージの初クリアで4ジェム、BOSS初クリアは既存宝箱も付与（宝箱内容は暫定）。通常24秒、AREA80型は6秒。7モンスター・33魂。ジェムはゲーム内のみで取得・使用。実際の課金はありません。
魂は青（常時・補助）、橙（攻撃回数）、緑（時間）、金（特殊・希少）に分類。全ステージからランダムドロップし、同一素材＋エーテルでレベルを強化。旧XP・凸は保存し、戦闘での自動レベルアップは停止。
アリーナは20ジェムで入場、対戦相手はNPC。連勝中は報酬を保留し、10勝ごとにモンスター1体分の獲得権。撤退で確定、敗北で未受取報酬を没収。ショップは1700ジェムで10体分の物資（試作100面の通常収入だけでは購入不可）。
戦闘中はポーズ・再開・設定・中止が可能。中止までに獲得した報酬を確定する。

## セーブ

v5の新キーへ非破壊移行。旧v1〜v4キーは保持。進行・資産・装着・記録を保持し、旧クリア報酬を補填。
別端末・別URL間の同期はありません。設定のJSON出力/復元を利用してください。
アプリ削除・ブラウザストレージ消去を避けてください。

## 構成とテスト

- index.html: HTML/CSS/純粋エンジン/UI/独自SVG
- sw.js: オフライン用キャッシュ（0.11.0）
- assets/: 既存素材・BGMとライセンス情報
- tests/: Node.js回帰試験、Chromium CDPブラウザ試験

```sh
node --test tests/*.test.cjs
node tests/browser-smoke.cjs
```

69件の回帰テストをGitHub ActionsのNode.jsで合格。通常戦闘・保存・オフラインのChromiumスモークも合格。全100面×7キャラの終了性を確認。アリーナの入場・対戦・勝利報酬受取とショップの実Chromium試験も合格。iPhone実機・公開反映は別途確認が必要。
原作と同じシステムを優先し、武器はモンスター、ルーンは魂として置換。正確な全種類・性能値・必要素材数・対戦HP・報酬量は暫定または未確認。独自名称・コード・素材を維持。
この版は再現専用開発ブランチ。公開URLはmain版を指す。
