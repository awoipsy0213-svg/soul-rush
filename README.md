## 遊び方

タイトル→ビルド→30秒戦闘→報酬→編成・重複強化→次のステージ。
ビルドのキャラを押すと横スクロールのキャラ選択、魂を押すとグリッド一覧。5つの装備構成を保存・比較可能。ホームの「範囲」「5ビルド比較」、魂一覧の検索・絞り込み・連続装着・強化表示を利用してください。
全ステージの初クリアで4ジェム、BOSS初クリアは既存宝箱も付与（宝箱内容は暫定）。通常30秒、AREA80型は6秒（アリーナ・Gift Runは24秒）。7モンスター・33魂。ジェムはゲーム内のみで取得・使用。実際の課金はありません。
魂は青（常時・補助）、橙（攻撃回数）、緑（時間）、金（特殊・希少）に分類。全ステージからランダムドロップし、同一素材＋エーテルでレベルを強化。旧XP・凸は保存し、戦闘での自動レベルアップは停止。
アリーナは20ジェム入場。1勝につき魂7個＋エーテル60、10勝ごとにモンスター1体分。撤退で報酬確定、敗北で未受取全没収。ショップは魂・モンスター・エーテル各3種の計9パックを再現。実決済なし。
AREAは1〜10000（実装上の安全上限）。100面ごとにボス構造を繰り返し、AREA移動で解放済み番号を直接指定可能。通常敵HPは20面以降の成長を緩和した仮曲線。
GIFTからデイリーギフトとGift Runに参加可能。各日1回、日本時間0時更新。未受取のラン報酬は保存され、再読込後に受取可能。ルール・報酬値は暫定。
キャラ選択の「外観」から紋章9種（装備なし含む）を選択。見た目のみ変化。ショップには隠し紋章の入手条件がある。
魂の発動ごとの自作SVG演出8系統と、結果の「戦闘詳細」に発動・命中・実ダメージ・無効回数を表示。
接敵・範囲・着弾・ゴールを個別処理。結果の戦闘詳細に最大ATK/SPD・DPS・命中数・移動・時間別ダメージ・余剰・残HPを表示。設定で軽量演出を選択可能。
戦闘中はポーズ・再開・設定・中止が可能。中止までに獲得した報酬を確定する。

## セーブ

v9の新キーへ非破壊移行。旧v1〜v8キーは保持。旧最速を保持し現行ルール記録は分離。通常精算は保存成功時のみ確定、失敗時は再試行可能。AREA100クリア済みなら101を解放し、過去報酬は再付与しない。進行・資産・装着・記録を保持し、旧クリア報酬を補填。
別端末・別URL間の同期はありません。設定のJSON出力/復元を利用してください。
アプリ削除・ブラウザストレージ消去を避けてください。

## 構成とテスト

- index.html: HTML/CSS/純粋エンジン/UI/独自SVG
- sw.js: オフライン用キャッシュ（0.15.0）
- assets/: 既存素材・BGMとライセンス情報
- data/balance.json: 調整用主要マスター（編集後に同期スクリプト実行）
- scripts/sync-balance.cjs: HTML組み込みと整合確認
- tests/: Node.js回帰試験、Chromium CDPブラウザ試験

```sh
node scripts/sync-balance.cjs --check
node --test tests/*.test.cjs
node tests/browser-smoke.cjs
```

v0.15はNode.js回帰131件合格・実ChromiumのUI/オフライン試験合格・マスター同期確認合格（Actions run 46087558860）。[画面キャプチャ](https://github.com/awoipsy0213-svg/soul-rush/actions/runs/46087558860/artifacts/15239985886)。初期モスAREA1は26.72秒、130戦楽観試算でAREA129到達。原作数値・全AREA攻略・iPhone実機は未確認。
原作の配信説明でデイリーギフト/Gift Run、2017年の攻略記事でヘルメット/ショップ連打による隠し外観を確認。具体的な仕様は仮設定。
原作と同じシステムを優先し、武器はモンスター、ルーンは魂として置換。アリーナ報酬・9物資の価格と数量は2017年Ver.1.9のプレイヤー実測に基づく。武器/ルーンの正確な全種類・効果量・必要素材数・対戦HP・後半敵HPは暫定または未確認。独自名称・コード・素材を維持。
