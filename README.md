## 起動

`index.html` をブラウザで開くと起動します。インターネット、外部ライブラリ、ビルド、サーバー、ログインは不要です。ブラウザによってはローカルHTMLの保存やスクリプト実行に制限があるため、iPhoneではHTTPS上での利用を推奨します。

## GitHub Pagesで公開する

1. GitHubで新規リポジトリ（例：`soul-rush`）を作成する。既存の別ゲームのリポジトリには混在させない。
2. ZIPを展開し、ZIP内のファイルとフォルダ（`.github/`、`.nojekyll` を含む） をリポジトリの `main` ブランチのルートに登録する。
3. GitHubの Settings → Pages → Build and deployment で Source を Deploy from a branch、Branch を `main`、フォルダを `/(root)` にして保存する。
4. Pagesに表示される公開URLを開く。公開可能なリポジトリとPages利用条件が必要です。

GitHub登録・Pagesの設定は完了済みです。上記のプレイURLを利用してください。

## 基本ループ

ロード → タイトル → メインターミナル → ステージ選択 / 出撃 → 出撃ロード → 戦闘（最大24秒） → リザルト → 再挑戦 / 次のステージ / ターミナル。ビルド・ショップ・設定・図鑑は独立シーン。

- 左に味方モンスター1体、右に敵が連続して並ぶ。敵が倒れると次の敵を即時攻撃する。
- 攻撃は自動。味方HPは設けない。全敵撃破時は残り時間に関係なく即時終了する。
- 制限時間内に全敵撃破できなければ同じステージへ再挑戦できる。敵は再挑戦時に全回復する。
- 撃破割合報酬 = floor(ステージ基準報酬 × 撃破数 ÷ 敵総数)。全敵撃破時にはクリア追加報酬を得て次ステージを解放する。
- 倒した敵1体につき経験値1。戦闘結果確定時に、出撃したモンスターへ付与しレベルアップを処理する。
- 敵撃破時に魂を入手。重複は素材として蓄積し、エーテルと一緒に消費して強化する。
- 過去に解放したステージは再挑戦できる。クリア追加報酬は再クリアでも得られる仮仕様。
- 魂は共通所持品。各モンスターに個別の装着構成を保存する。適性・装着枠による制限がある。
- エーテルを消費してモンスターを召喚、魂を習得・強化する。
- 戦闘開始時のステータス・魂構成を固定。戦闘中は装備・購入・ステージ変更不可。
- localStorageに結果・購入・装着等を自動保存。未完了の戦闘を再開する機能はない。別端末や別URLへは自動移行しない。

## 初期コンテンツ（全て仮仕様）

モンスター4種：モス（均衡）、ヴォルフ（高速）、グラント（重撃）、イグニス（多能力）。攻撃力・秒間攻撃数・魂の適性・3〜5個の装着枠で差別化。

魂13種：追加6種（会心・氷結・幸運・反響・流星・巨人）と既存7種（力（攻撃力）、疾風（攻撃速度）、雷鳴（4攻撃ごと）、爆炎（5秒ごと）、捕食（撃破時の戦闘内強化）、貫通（余剰ダメージ）、月蝕（10秒ごと））。全て独自のSVGアイコン。

ステージはパラメータから生成。通常・重装・大群・ボスを含み、試験上限100ステージ。難易度曲線は正式なバランス調整前で、後半の攻略可能性は未検証。
