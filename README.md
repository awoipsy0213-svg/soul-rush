## 遊び方

タイトル→ビルド→24秒戦闘→報酬→編成・重複強化→次のステージ。
ビルドのキャラを押すと横スクロールのキャラ選択、魂を押すとグリッド一覧。5つの装備構成を保存可能。
全ステージの初クリアで4ジェム、BOSS初クリアは既存宝箱も付与（宝箱内容は暫定）。通常24秒、AREA80型は6秒。7モンスター・33魂。ジェムはゲーム内のみで取得・使用。実際の課金はありません。
魂は青（常時・補助）、橙（攻撃回数）、緑（時間）、金（特殊・希少）に分類。全ステージからランダムドロップし、同一素材＋エーテルでレベルを強化。旧XP・凸は保存し、戦闘での自動レベルアップは停止。
アリーナは20ジェム入場。1勝につき魂7個＋エーテル60、10勝ごとにモンスター1体分。撤退で報酬確定、敗北で未受取全没収。ショップは魂・モンスター・エーテル各3種の計9パックを再現。実決済なし。
AREAは1〜10000（実装上の安全上限）。100面ごとにボス構造を繰り返し、AREA移動で解放済み番号を直接指定可能。通常敵HPは20面以降の成長を緩和した仮曲線。
戦闘中はポーズ・再開・設定・中止が可能。中止までに獲得した報酬を確定する。

## セーブ

v6の新キーへ非破壊移行。旧v1〜v5キーは保持。AREA100クリア済みなら101を解放し、過去報酬は再付与しない。進行・資産・装着・記録を保持し、旧クリア報酬を補填。
別端末・別URL間の同期はありません。設定のJSON出力/復元を利用してください。
アプリ削除・ブラウザストレージ消去を避けてください。

- index.html: HTML/CSS/純粋エンジン/UI/独自SVG

```sh
node --test tests/*.test.cjs

```
